# 할일

## 개요
사용자가 해야 할 일을 등록하고 관리한다.

## 할일의 흐름
할일을 만들면 "대기" 상태가 된다.
작업을 시작하면 "진행중"으로 바뀌고, 끝나면 "완료"가 된다.
완료된 할일은 다시 되돌릴 수 없다.

## 기본 규칙
- 할일에는 반드시 제목이 있어야 한다
- 제목은 빈 문자열일 수 없다
- 마감일을 설정할 수 있고, 과거 날짜는 안 된다
- 우선순위는 높음, 보통, 낮음 중 하나이며 기본은 보통이다

## 절대 깨지면 안 되는 것들
- 제목 없는 할일은 만들 수 없다
- 완료된 할일의 상태는 바꿀 수 없다
- 존재하지 않는 할일을 조회하면 적절히 알려줘야 한다
- 잘못된 상태 변경 요청은 거부해야 한다
