# 평가 기준

## 반드시 통과해야 하는 것 (하나라도 실패하면 reject)
- 빌드가 성공한다
- 서버가 정상적으로 뜬다
- 기존에 있던 테스트가 모두 통과한다
- domain/ 문서의 "절대 깨지면 안 되는 것들"이 전부 테스트로 검증된다
- 도메인 문서에 서술된 시나리오가 실제로 동작한다

## 검증 방법
1. ./gradlew build 실행 → 빌드 및 테스트 통과 확인
2. ./gradlew bootRun으로 서버 기동
3. curl로 API 호출하여 시나리오 동작 확인
4. 서버 종료

## 결과 보고
사이클 종료 후 다음을 보고한다:
- 발견한 간극 목록
- 수행한 코드 변경 요약
- 생성한 테스트 목록과 통과 여부
- API 호출 검증 결과
- 전체 평가 판정 (pass/fail)
